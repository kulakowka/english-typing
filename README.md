# english_typing

Тренажёр английских фраз для русскоязычных: https://english.antonkulakov.com

Видишь русскую фразу или фотографию, печатаешь по-английски по памяти. Младший брат [code_typing](https://typing.antonkulakov.com).

Темы трёх типов:

- **Фразы** — русская фраза → английская. 10 тем, 640 фраз.
- **Времена** — выбираешь время и печатаешь предложения в нём: утверждения, отрицания, вопросы. 8 времён, 288 предложений.
- **Слова по картинкам** — фотография → слово. 18 тем, 576 слов: предметы, глаголы, люди, профессии, чувства, цвета и фигуры.

- новая фраза сначала списывается с образца, через карточку спрашивается по памяти
- каждая клавиша проверяется сразу, неверная не вводится
- подсказки лесенкой по Tab: буква, слово, вся фраза; с подсказкой фраза вернётся раньше
- ловушки русскоязычных: на «depends f…» сразу объяснение
- в конце сессии раунд ловушек: вписать только слова, на которых споткнулся
- повторы по дням: 1, 3, 7, 16, 35; со второй ступени набор вслепую, без чёрточек
- после набора фраза звучит (Web Speech API), если в браузере есть английский голос
- экранная клавиатура с пальцами (⌘J): в знакомстве подсвечивает следующую клавишу, по памяти показывает палец после нажатия
- выбор темы по ⌘K. Фразы: общие, small talk, путешествия, еда и рестораны, здоровье, работа и офис, деловая переписка, собеседование, IT, фразовые глаголы. Слова: еда и напитки, кухня и посуда, дом и мебель, одежда, животные, город и транспорт, природа и погода, техника и офис, тело, профессии, спорт и хобби, чувства и состояния, семья и люди, школа, инструменты, цвета и фигуры, действия на каждый день, действия-движения
- у времён первая подсказка по Tab — правило формы, оно тоже не считается подсказкой
- у слов первая подсказка по Tab — перевод: картинку можно понять по-разному, поэтому перевод не считается подсказкой
- прогресс хранится в `localStorage`, регистрации нет

Без сборки и зависимостей: статичные файлы в `public/`.

| Файл | Что в нём |
| --- | --- |
| `core.js` | нормализация, варианты ответа, ловушки; без DOM |
| `app.js` | сессия, набор, оценка, повторы, экран итога |
| `speech.js` | озвучка |
| `keyboard.js` | экранная клавиатура и пальцы |
| `phrases/*.js` | темы с фразами, по файлу на тему |
| `tenses/*.js` | времена: предложения с пометкой формы и правила |
| `words/*.js` | темы со словами |
| `img/<тема>/<слово>.webp` | картинки к словам, 512×512 |

## Как добавить фразу

```js
{ id: 'g-depends-weather',            // уникальный и постоянный: на нём держится прогресс
  ru: 'Это зависит от погоды.',
  ctx: 'разговор',                    // ситуация, до 28 символов
  en: ['It depends on the weather.',  // первый вариант целевой, остальные тоже принимаются
       'That depends on the weather.'],
  note: 'Depend on — всегда *on*.',   // *так* выделяется жирным
  traps: [
    { after: 'depends ', keys: 'f', say: '«Зависит от» = depends *on*.' }
  ] }
```

- Знак в конце печатается, как и вся фраза; точка и восклицательный знак равнозначны. Запятые необязательны: они встают сами.
- Одна фраза — одно предложение, до 11 слов и 64 символов. Только буквы, цифры, пробел, запятая, прямой апостроф, дефис и знак в конце.
- Пары вроде `I'm` и `I am` в `en` писать не надо: они добавляются сами.
- Ловушка срабатывает, когда набранное заканчивается на `after`, а неверная клавиша входит в `keys`. С `start: true` набранное должно совпасть с `after` целиком. `after` может быть массивом.
- Новая тема — новый файл в `public/phrases/` и строка `<script>` в `index.html`.

## Как добавить предложение во время

Строка в `public/tenses/<время>.js`:

```js
['-', 'Она не пьёт кофе.', "She doesn't drink coffee.", [['she do', 'n', "С he, she, it — *doesn't*.", true]]],
```

Форма (`+` утверждение, `-` отрицание, `?` вопрос), русское предложение, английские варианты через `|`, ловушки `[after, keys, say, start?]` и, если нужно, своя заметка. Правило для каждой формы лежит в `forms` темы: оно показывается по первому Tab и после ответа.

## Как добавить слово

Строка в `public/words/<тема>.js`:

```js
['sofa|couch', 'диван', 'a sofa'],   // слово и другие верные варианты, перевод, что на картинке
```

Картинки генерируются листами 3×3, по девять слов на лист (в 9 раз дешевле, чем по одной):

```bash
node tools/word-sheets.mjs                 # запросы для генератора картинок, по одному на лист
node tools/slice-sheets.mjs <папка>        # режет листы <тема>-<номер>.png на картинки слов
```

Все 576 картинок сделаны в Higgsfield моделью GPT Image 2.6: 64 листа 2048×2048.

У темы может быть поле `ask` — вопрос на карточке: «Что здесь делают? Нужен глагол.» Без него спрашивается «Что на картинке?».

Проверка колод:

```bash
node tools/check-phrases.mjs
```

## Запуск и выкладка

```bash
python3 -m http.server 4173 --directory public
```

Выкладка: пуш в `main`. GitHub Actions проверяет колоды и выкладывает сайт на Firebase Hosting.

`/#debug` добавляет на экран итога кнопку перемотки дней, чтобы проверить повторы.
