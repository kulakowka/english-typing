# english_typing

Тренажёр английских фраз для русскоязычных: https://english.antonkulakov.com

Видишь русскую фразу, печатаешь английскую по памяти. Младший брат [code_typing](https://typing.antonkulakov.com).

- новая фраза сначала списывается с образца, через карточку спрашивается по памяти
- каждая клавиша проверяется сразу, неверная не вводится
- подсказки лесенкой по Tab: буква, слово, вся фраза; с подсказкой фраза вернётся раньше
- ловушки русскоязычных: на «depends f…» сразу объяснение
- в конце сессии раунд ловушек: вписать только слова, на которых споткнулся
- повторы по дням: 1, 3, 7, 16, 35; со второй ступени набор вслепую, без чёрточек
- после набора фраза звучит (Web Speech API), если в браузере есть английский голос
- экранная клавиатура с пальцами (⌘J): в знакомстве подсвечивает следующую клавишу, по памяти показывает палец после нажатия
- 10 тем, 640 фраз, выбор по ⌘K: общие, small talk, путешествия, еда и рестораны, здоровье, работа и офис, деловая переписка, собеседование, IT, фразовые глаголы
- прогресс хранится в `localStorage`, регистрации нет

Без сборки и зависимостей: статичные файлы в `public/`.

| Файл | Что в нём |
| --- | --- |
| `core.js` | нормализация, варианты ответа, ловушки; без DOM |
| `app.js` | сессия, набор, оценка, повторы, экран итога |
| `speech.js` | озвучка |
| `keyboard.js` | экранная клавиатура и пальцы |
| `phrases/*.js` | колоды, по файлу на тему |

## Как добавить фразу

```js
{ id: 'g-depends-weather',            // уникальный и постоянный: на нём держится прогресс
  ru: 'Это зависит от погоды.',
  ctx: 'разговор',                    // ситуация, до 28 символов
  en: ['It depends on the weather.',  // первый вариант целевой, остальные тоже принимаются
       'That depends on the weather.'],
  note: 'Depend on — всегда *on*.',   // *так* выделяется жирным
  traps: [
    { after: 'depends ', keys: 'f', say: '«Зависит от» = depends *on*.' }
  ] }
```

- Знак в конце печатается, как и вся фраза; точка и восклицательный знак равнозначны. Запятые необязательны: они встают сами.
- Одна фраза — одно предложение, до 11 слов и 64 символов. Только буквы, цифры, пробел, запятая, прямой апостроф, дефис и знак в конце.
- Пары вроде `I'm` и `I am` в `en` писать не надо: они добавляются сами.
- Ловушка срабатывает, когда набранное заканчивается на `after`, а неверная клавиша входит в `keys`. С `start: true` набранное должно совпасть с `after` целиком. `after` может быть массивом.
- Новая тема — новый файл в `public/phrases/` и строка `<script>` в `index.html`.

Проверка колод:

```bash
node tools/check-phrases.mjs
```

## Запуск и выкладка

```bash
python3 -m http.server 4173 --directory public
```

Выкладка: пуш в `main`. GitHub Actions проверяет колоды и выкладывает сайт на Firebase Hosting.

`/#debug` добавляет на экран итога кнопку перемотки дней, чтобы проверить повторы.
